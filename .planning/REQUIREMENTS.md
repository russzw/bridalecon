# BridalEcon — Requirements (Milestone 1)

## Milestone Goal

Transform BridalEcon into a polished, feature-rich web application with a stunning UI, AI insights, and deep data.

## Scope

### Must Have (P0)

- **M1** — Design System: tokens, typography, dark/light mode palette.
- **M2** — Mobile-first layout redesign.
- **M3** — Dark / Light mode toggle.
- **M4** — Globe visual upgrade (theme-aware).
- **M5** — Country Profiles: rich structured data pages.
- **M6** — AI Recommendations (Gemini).
- **M7** — AI Chat widget.
- **M8** — Timeline & Trends charts.
- **M9** — Ethical Analysis section.

### Should Have (P1)

- **S1** — Command-palette search (⌘K).
- **S2** — Data sources page.
- **S3** — Performance audit (LCP < 2.5s).

## Acceptance Criteria

- Pages render correctly on mobile and desktop.
- Dark/light mode toggle works without flash.
- AI features provide contextually relevant info.
- Lighthouse scores ≥ 85.
